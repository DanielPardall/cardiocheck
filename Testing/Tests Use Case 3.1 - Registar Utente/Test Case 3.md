# Test Case #3: Verificação de unicidade

## Pré-condições

- O utilizador deve estar no formulário de registo do utente.

## Passos

1. O utilizador preenche o "Número de Utente de Saúde" e "E-mail" com valores que já existem na base de dados.
2. O utilizador preenche os restantes campos corretamente.
3. O utilizador clica no botão "Registar".

## Resultado esperado

- O sistema verifica a unicidade do "Número de Utente de Saúde" e do "E-mail" e informa o utilizador caso já estejam registados.
