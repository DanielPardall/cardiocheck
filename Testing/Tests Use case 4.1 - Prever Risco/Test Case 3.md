# Test Case #3: Guardar o resultado da previsão

## Pré-condições

- Uma previsão de risco foi calculada e está sendo exibida na interface.

## Passos

1. O utilizador clica no botão "Guardar Resultado".

## Resultado esperado

- O sistema deve guardar o resultado da previsão na base de dados das previsões, associando-o ao utente específico.
- O sitema deve confirmar o utilizador que o resultado foi guardado com sucesso.
