# Test Case #12: Redirecionamento após Sucesso no Registo

## Pré-condições

- O utilizador foi registado com sucesso.

## Steps

1. O sistema exibe a mensagem "Registado com sucesso!".
2. O sistema redireciona o utilizador para o pop-up de Login.

## Resultado esperado

O sistema deve redirecionar o utilizador para o pop-up de Login após um registo bem sucedido.

## Execuções

- Execução 1: Não Ok, o sistema não redireciona para o pop-up de Login.
- Execução 2: Ok, o sistema redireciona para o pop-up de Login.
