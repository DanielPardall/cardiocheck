# Teste Case #1: Verificação de preenchimento de todos os campos

## Pré-condições

- O utilizador dever ter acesso à aplicação.
- O utilizador deve conseguir clicar no botão "Registo" para que o pop-up de Registo apareça.

## Passos

1. O utilizador clica no botão "Registo".
2. O utilizador acessa o pop-up de Registo.
3. O utilizador tenta submeter o formulário com um ou mais campos em branco.

## Resultado esperado

- O sistema deve validar que todos os campos são obrigatórios e informar o utilizador dos campos que precisam ser preenchidos.

## Execuções

- Execução 1: Não Ok, o sistema não indica quais campos são obrigatórios.
- Execução 2: Ok, o sistema indica todos os campos como obrigatórios e não permite o registo até estarem todos preenchidos.
