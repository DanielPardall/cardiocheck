# Test Case #8: Verificação de E-mail existente na Base de Dados

## Pré-condições

- O utilizador já inseriu corretamente todos os campos anteriores.

## Passos

1. O utilizador insere um endereço de e-mail que já se encontra registado na base de dados.
2. Clica no botão "Registar".

## Resultado esperado

- O sistema deve verificar se o e-mail já está registado e informar o utilizador caso esteja.

## Execuções

- Execução 1: Não Ok, o sistema permite o registo de um e-mail já existente.
- Execução 2: Ok, o sistema informa que o e-mail já está em uso.
