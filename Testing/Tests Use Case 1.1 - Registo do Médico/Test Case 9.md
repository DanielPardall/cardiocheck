# Test Case #9: Verificação de Número de Cédula Existente na Base de Dados

## Pré-condições

- O utilizador já inseriu corretamente todos os campos anteriores.

## Passos

1. O utilizador insere um número de cédula profissional que já se encontra registado na base de dados.
2. Clica no botão "Registar".

## Resultado esperado

- O sistema deve verificar se o número de cédula já está registado e informar o utilizador caso esteja.

## Execuções

- Execução 1: Não Ok, o sistema permite o registo de um número de cédula já existente.
- Execução 2: Ok, o sistema informa que o número de cédula já está em uso.
