# Test Case #3: Eliminar conta e redirecionamento  

## Pré-condições

- O modal confirmação da eliminação da conta está exibido.

## Passos

1. O utilizador clica no botão "Sim" no modal.

## Resultado esperado

- A conta do utilizador deve ser removida da base de dados.
- O utilizador é redirecionado para a página inicial de login/registo.

## Execuções

- Execução 1: Não Ok, a conta do utilizador não é removida da base de dados.
- Execução 2: Ok, a conta do utilizador é removida e o redirecionamento ocorre corretamente.
