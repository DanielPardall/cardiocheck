# Test Case #5: Redirecionamento após login bem sucedido

## Pré-condições

- O utilizador efetuou o login com sucesso.

## Passos

1. O utilizador insere um endereço de e-mail e palavra-passe válidos.
2. O utilizador clica no botão "Login".
3. Aguardar a mensagem de sucesso seguida do redirecionamento automático.

## Resultado esperado

- O sistema deve redirecionar o utilizador para a página correta dentro da aplicação.

## Execuções

- Execução 1: Ok, o utilizador é redirecionado como esperado.
