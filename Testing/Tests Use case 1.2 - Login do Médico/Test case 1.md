# Test Case #1: Verificação de credenciais incorretas

## Pré-condições

- O utilizador abriu o pop-up de Login.

## Passos

1. O utilizador insere um endereço de e-mail ou palavra-passe incorretos.
2. O utilizador clica no botão "Login".

## Resultado esperado

- O sistema deve apresentar uma mensagem de erro "E-mail ou palavra-passe incorretos!".

## Execuções

- Execução 1: Ok, a mensagem de erro é apresentada corretamente.
