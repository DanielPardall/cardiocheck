# Test Case #2: Desaparecimento automático da mensagem de erro

## Pré-condições

- O utilizador recebeu uma mensagem de erro após tentativa de login.

## Passos

1. O utilizador clica no botão "Login" com a inserção de credenciais incorretas.
2. Observa o comportamento da mensagem de erro após ser exibida.

## Resultado esperado

- A mensagem de erro deve desaparecer automaticamente após alguns segundos.

## Execuções

- Execução 1: Ok, a mensagem de erro desaparece após um curto período de tempo.
