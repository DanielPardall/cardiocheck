# Test Case #3: Funcionalidade do botão de Login após erro

## Pré-condições

- O utilizador tentou fazer login com credenciais incorretas e recebeu uma mensagem de erro.

## Passos

1. O utilizador corrige as credenciais.
2. Clica novamente no botão "Login".

## Resultado esperado

- O botão de Login deve estar funcional e permitir uma nova tentativa de login após a primeira tentativa mal sucedida.

## Execuções

- Execução 1: Ok, o botão de Login permite uma nova tentativa como esperado.
