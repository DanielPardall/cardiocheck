# Test Case #6: Reset do formulário e disponibilidade dos botões após "navegação de histórico"

## Pré-condições

- O utilizador foi redirecionado para a nova página após um login bem sucedido.

## Passos

1. O utilizador regressa à página de login/registo utilizando a navegação pelo histórico do navegador.
2. Observar o estado dos formulários e dos botões de Login e Registo.

## Resultado esperado

- Os formulários de login e registo devem ser resetados e os botões de Login e Registo devem estar disponíveis.

## Execuções

- Execução 1: Não ok, os botões estão indisponíveis.
- Execução 2: Não Ok, os formulários mantêm os dados anteriores.
- Execução 3: Ok, os formulários são resetados e os botões estão disponíveis para uma nova ação.
