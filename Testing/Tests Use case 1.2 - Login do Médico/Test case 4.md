# Test Case #4: Verificação de Login bem sucedido

## Pré-condições

- O utilizador abriu o pop-up de Login.

## Passos

1. O utilizador insere um endereço de e-mail e palavra-passe válidos e correspondentes na base de dados.
2. O utilizador clica no botão "Login".

## Resultado esperado

- O sistema deve autenticar o utilizador e exibir a mensagem "Login bem sucedido!".

## Execuções

- Execução 1: Não ok, o utilizador foi redirecionado para uma nova página sem que uma mensagem de sucesso fosse exibida primeiro.
- Execução 2: Ok, o utilizador é autenticado com sucesso e a mensagem é exibida.
