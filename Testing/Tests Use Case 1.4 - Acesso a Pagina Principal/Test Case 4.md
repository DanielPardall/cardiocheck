# Test Case #4: Visualização dos elementos na página principal

## Pré-condições

- O utilizador tem o login efetudado.
- Encontra-se na página principal.

## Passos

1. O utilizador verifica a presença da barra de pesquisa de utentes.
2. O utilizador verifica a presença do botão para registar novos utentes.

## Resultado esperado

- A barra de pesquisa de utentes e o botão para registar novos utentes devem estar visíveis e acessíveis na página principal.

## Execuções

- Execução 1: Não Ok, a barra de pesquisa ou o botão de registo de utentes não aparecem conforme esperado.
- Execução 2: Ok, ambos os elementos estão presentes na página principal.
