# Test Cenário #4: Testes de Cobertura do Código

## Pré-condições

- A equipa de desenvolvimento tem acesso ao código completo e aos seus testes.

## Passos

1. A equipa de desenvolvimento analisa o código fonte.
2. A equipa de desenvolvimento analisa os testes feitos ao código.
3. A equipa de desenvolvimento verifica quais as partes do código que funcionam corretamente e os respetivos testes.

## Resultado esperado

- O código testado estar a funcionar corretamente e os testes realizados terem tido sucesso.
