# Test Case #2: Encerrar sessão

## Pré-condições

- O modal de confirmação de encerramento de sessão está exibido.

## Passos

1. O utilizador clica no botão "Sim" no modal.

## Resultado esperado

- A sessão do utilizador deve ser encerrada.
- O utilizador é redirecionado para a página inicial de login/registo.

## Execuções

- Execução 1: Não Ok, o utilizador não é redirecionado para a página inicial.
- Execução 2: Ok, a sessão é encerrada e o utilizador é redirecionado para a página inicial como esperado.
