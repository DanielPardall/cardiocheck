## Cenário de Qualidade de Usabilidade 1: Utilização eficiente do sistema

- **Origem do Estímulo:** Médico validado pelo sistema.

- **Estímulo:** Navegar no sistema.

- **Ambiente:** Sistema em funcionamento normal.

- **Artefato:** Sistema

- **Resposta:** O sistema é simples de usar, com linhas simples, uma interface limpa e animações intuitivas.

- **Medida de Resposta:** O médico consegue usar sistema, sem problemas.


## Cenário de Qualidade de Usabilidade 2: Minimização do impacto dos erros (FEITO)

- **Origem do Estímulo:** Médico validado pelo sistema.

- **Estímulo:** Inserção incorreta de dados clínicos.

- **Ambiente:** Sistema em funcionamento normal.

- **Artefato:** Sistema de previsão de doenças caridíacas.

- **Resposta:** O sistema valida os dados em tempo real e notifica o médico sobre inconsistências comuns, oferecendo a possibilidade de correção imediata.

- **Medida de Resposta:** O sistema deve identificar e notificar o médico sobre o erro em menos de 2 segundos após a entrada incorreta de dados.

## Cenário de Usabilidade 3: Aumentar a confiança e satisfação (FEITO)

- **Origem do Estímulo:** Médico validado pelo sistema.

- **Estímulo:** Uso contínuo do sistema.

- **Ambiente:** Sistema em funcionamento normal.

- **Artefato:** Sistema.

- **Resposta:** O sistema é otimizado e fluído, sem erros.

- **Medida de Resposta:** O sistema não deve demorar mais do que 3 segundos seja em que operação for.
